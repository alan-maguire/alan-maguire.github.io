# Alan Maguire

## About me

Linux kernel engineer interested in BPF, observability, AI,
networking.

Creator of [bpftune](https://github.com/oracle/bpftune) -
BPF-based auto-tuning of Linux systems.

Co-maintainer of [pahole](https://github.com/acmel/dwarves) - 
examine, translate and create debug info; used in the kernel
to create kernel/module BPF Type Format (BTF) information
critical to BPF operation.
